# Smart Expense Tracker & Analytics

A privacy-first personal finance web application that helps users track income and expenses, manage budgets, understand spending patterns, and export detailed financial reports.

## Project Goal

Build a beginner-friendly but professional full-stack web app that turns daily financial records into useful insights.

## Key Features

### MVP Features

- Add, edit and delete income and expenses
- Manage spending categories
- View monthly income, expenses and balance
- View transaction history
- Simple dashboard

### Advanced Features

- Category budgets and overspending alerts
- Savings goals
- Analytics dashboard with charts
- Monthly reports
- CSV import/export
- Monthly PDF report export with visual charts
- Recurring transactions
- Smart auto-categorization
- Optional receipt OCR

## Main Pages

- Dashboard
- Add Transaction
- Transactions
- Budgets
- Analytics
- Reports
- Settings

## Technology Stack

- HTML, CSS and JavaScript
- Python
- Flask
- SQLite
- SQLAlchemy
- pandas
- Matplotlib
- ReportLab
- Chart.js
- pytest
- Git and GitHub

## Privacy Approach

All financial data will be stored locally using SQLite. The MVP will not require bank login, cloud storage or paid services.
