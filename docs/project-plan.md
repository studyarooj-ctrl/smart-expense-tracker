# Smart Expense Tracker & Analytics

## Project Goal
Build a privacy-first personal finance web app that helps users track income and expenses, manage budgets, understand spending patterns, and receive useful financial insights.

## Target Users
- Students
- Young professionals
- Freelancers
- Anyone who wants to control monthly spending

## MVP Features
- Add income and expenses
- Manage categories
- View monthly income, expenses and balance
- View, edit and delete transactions
- Simple dashboard

## Advanced Features
- Category budgets and overspending alerts
- Savings goals
- Analytics charts
- Monthly reports
- CSV import/export
- Recurring transactions
- Smart auto-categorization
- Optional receipt OCR
- Monthly financial report PDF export with summary, category breakdown, visual charts, transactions, top expenses, budget status and insights

## Main Pages
- Dashboard
- Add Transaction
- Transactions
- Budgets
- Analytics
- Reports
- Settings

## Technology Stack
- HTML, CSS, JavaScript
- Python
- Flask
- SQLite
- SQLAlchemy
- pandas
- Chart.js
- pytest
- Git and GitHub
- Matplotlib for PDF report charts and analytics visuals
- ReportLab for PDF report generation

## Privacy Approach
All financial data will be stored locally using SQLite. No bank login or cloud storage will be required for the MVP.
